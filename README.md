# 🛠️ DevTools Hub

> 20 tools developer ringan — jalan di CLI dan browser. 100% client-side.

## Fitur

- Web app Next.js 16 + Tailwind v4
- CLI dengan 20+ subcommand
- 100% client-side
- Monorepo

## Tools

| Kategori | Tools |
|----------|-------|
| Encoding | Base64, JSON, YAML, URL, MIME |
| Text | Case, Slug, Regex, Diff, Lorem, Markdown |
| Security | Hash, JWT, Password |
| Time | Timestamp, Cron |
| Design | Color, QR |
| Misc | UUID, Semver |

## Cara Pakai

### Web

    git clone https://github.com/Syqmhmmd-commits/devtools-hub.git
    cd devtools-hub
    pnpm install
    pnpm dev

### CLI

    pnpm cli b64 encode "hello world"
    pnpm cli uuid -c 5
    pnpm cli --help
