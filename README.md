# 🛠️ DevTools Hub

[![Live Demo](https://img.shields.io/badge/demo-live-6366f1?style=for-the-badge)](https://syqmhmmd-commits.github.io/devtools-hub/)

20 tools developer ringan — jalan di CLI dan browser. 100% client-side.

## Tools

- 📦 **Encoding**: Base64, JSON, YAML, URL, MIME
- 🔤 **Text**: Case, Slug, Regex, Diff, Lorem, Markdown
- 🔒 **Security**: Hash, JWT, Password
- ⏰ **Time**: Timestamp, Cron
- 🎨 **Design**: Color, QR
- 🆔 **Misc**: UUID, Semver

## Quick Start

### Web App

```bash
git clone https://github.com/Syqmhmmd-commits/devtools-hub.git
cd devtools-hub
pnpm install
pnpm dev
```

Buka http://localhost:3000

### CLI

```bash
dt b64 encode "hello"
dt uuid -c 5
dt hash "hello"
dt color "#3b82f6"
dt list
```
